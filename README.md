# Day Dream — Downloads

**Day Dream** is a desktop AI animation studio. Type an idea and it plans the story, draws every
scene, records the voice-over and exports a video, or builds a whole manga chapter. Everything runs
on your own computer.

## ⬇️ Download

Get the latest installer from **[Releases → Latest](../../releases/latest)**.

| System | File |
|---|---|
| macOS 12+ — Apple Silicon (M1–M4) | `DayDream-<version>-mac-arm64.dmg` |
| macOS 12+ — Intel | `DayDream-<version>-mac-x64.dmg` |
| Windows 10/11 — 64-bit | `DayDream-<version>-win-x64.exe` |
| Windows 10/11 — ARM | `DayDream-<version>-win-arm64.exe` |
| Linux x64 / ARM64 | `.AppImage`, `.deb` or `.tar.gz` |

## Install

- **macOS:** open the `.dmg` and drag Day Dream to Applications. If macOS blocks it, go to
  *System Settings → Privacy & Security* and click **Open Anyway**.
- **Windows:** run the `.exe`. It installs for your user only, no admin rights needed. If
  SmartScreen warns you, click **More info → Run anyway**.
- **Linux:** `chmod +x DayDream-*.AppImage` and run it, or `sudo apt install ./DayDream-*.deb`.

**First launch needs the internet once** (2–5 minutes): Day Dream sets up its private runtime and
shows each step. After that it starts offline in about a second.
